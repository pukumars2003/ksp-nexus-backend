# KSP Nexus Backend

This is the Python FastAPI backend for the **KSP Nexus** project.

Please refer to the main [Project README](../README.md) at the root of the repository for full details on the features, AI Chat architecture, Voice Processing pipeline, and recent updates.

## Getting Started

First, ensure your virtual environment is active:
```bash
venv\Scripts\activate
```

Then, run the backend server:

```bash
uvicorn main:app --reload --port 8000
```
